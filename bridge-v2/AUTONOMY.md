# Автономный цикл (только архитектура)

Этот файл описывает будущий цикл. Он **не включает** его и **не добавляет**
действий. Живой mailbox по-прежнему выключен, пока нет локального
`mailbox.json`, и этот этап такой файл не создаёт.

## Цикл после отдельного включения

1. Взять одну задачу. Снаружи допустим только action id из четырёх
   действий только для чтения: `GIT_VERSION`, `GIT_STATUS`, `GIT_LOG10`,
   `GIT_DIFF`. Текст команды не принимается.
2. Внести правку.
3. Запустить тест.
4. Прочитать провал.
5. Исправить.
6. Повторять 2–5, пока провал не исчезнет.
7. Просмотреть diff на секреты. Токен, PAT и клиентский секрет в git не попадают.
8. Полный smoke-test с фейковыми `git` и `gh`.
9. После критического изменения Bridge одного зелёного прогона мало: второй
   чистый smoke с нуля, без переиспользования прошлой песочницы.
10. Коммит и push в `main`.
11. Короткий отчёт: полный hash и одна проверка на Windows.

Модель не получает секрет GitHub и не получает admin-оболочку.

## Чего здесь нет

Повышенный helper **не реализован** и в этом изменении не включается.
Будущая модель, если она когда-нибудь понадобится: маленький доверенный
процесс со своим закрытым списком операций. Это не shell для модели и не
способ выполнить текст, пришедший из GitHub.

AI никогда не получает административную оболочку. Подтверждение человека
остаётся на критической границе, а не на каждом чтении `git status`.

## Граница доверия

GitHub — транспорт. Текст задания, поле автора внутри JSON и метаданные
коммита не являются разрешением. Разрешение — права приватного mailbox:
не форк, точное имя, владелец `dvikt33-ux`, нет лишнего push/admin/maintain,
нет deploy key. Если этот ответ прочитать нельзя, задача не выполняется.

Ограничение явное: скомпрометированный аккаунт владельца всё ещё может
поставить в очередь одно из четырёх действий только для чтения. Подпись
ради видимости безопасности не подделывается.
