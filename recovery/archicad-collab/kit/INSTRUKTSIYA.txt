СОВМЕСТНАЯ РАБОТА В ARCHICAD — ИНСТРУКЦИЯ ДЛЯ ВТОРОЙ МАШИНЫ
Версия инструкции: 2026-09-11. Фаза A (тесты синхронизации).

ЧТО ЭТО
  Набор скриптов для проверки связи "компьютер — Archicad 29 — Tapir"
  и первых тестов синхронизации между двумя машинами.
  Скрипты ничего лишнего не трогают: про опасные шаги всегда спрашивают.

ЧТО НУЖНО ЗАРАНЕЕ
  - Windows 10/11, 64-bit.
  - Archicad 29.0.0.3000 RUS (именно эта сборка).
  - Интернет.
  - Файл проекта "тропа архикад.pln" — пришлёт коллега отдельно.

БЫСТРЫЙ СТАРТ (5–15 минут)
  1. Распакуйте ZIP в любую папку, например Документы\accollab.
  2. Двойной клик по setup.bat. Он сам:
     - проверит Python; если нет — скачает 3.12 и тихо поставит
       только для вас (прав администратора не надо);
     - скачает Tapir 1.5.9 с официального GitHub и снимет
       блокировку Windows;
     - положит Tapir в Add-Ons Archicad (если хватит прав);
     - запустит проверку готовности.
  3. Если setup.bat написал "нет записи в Add-Ons" (нет прав админа):
     - откройте Archicad 29 → Параметры → Диспетчер надстроек;
     - кнопка Add/Добавить → выберите файл TapirAddOn_AC29_Win.apx
       из папки кита → OK.
  4. Перезапустите Archicad (иначе Tapir не подхватится).
  5. Положите рядом файл "тропа архикад.pln" от коллеги, откройте в AC29.
  6. Во время тестов держите запущенным ТОЛЬКО Archicad 29
     (26/27/28 закрыты), все диалоги в Archicad закрыты.

ПРОВЕРКА (пришлите скриншоты коллеге)
  1. 00-check.bat → должно быть "GOTOVO: mashina k testam gotova".
     Если "NE GOTOVO" — там же написано, что чинить.
  2. 01-diag.bat → в конце elementCount около 393.
  3. 02-highlight.bat → 3 балки на плане станут синими.
     (Подсветка временная, проект не меняется.)

ЕСЛИ ЧТО-ТО ЗАВИСЛО ИЛИ ОШИБКА
  - "Timed out" / тишина: закройте ВСЕ диалоги в Archicad, кликните
    в окно проекта, убедитесь что Archicad запущен один, повторите.
  - Порт "molchit": перезапустите Archicad (иногда он переезжает
    с порта 19723 на 19724 — скрипты ищут сами, но инстанс зомби
    лучше убить рестартом).
  - Python не ставится: проверьте интернет, загляните в setup.log
    рядом с setup.bat; вручную — https://www.python.org/downloads/
    (3.12, при установке галочка Add to PATH).
  - Tapir не качается: вручную —
    https://github.com/ENZYME-APD/tapir-archicad-automation/releases
    (версия 1.5.9, файл TapirAddOn_AC29_Win.apx), затем свойства
    файла → "Разблокировать" → в папку Add-Ons → рестарт Archicad.

СИНХРОНИЗАЦИЯ МЕЖДУ ДВУМЯ МАШИНАМИ
  На машине A (там, где двигают):
    1. 03-export.bat → первый раз сохранит базу (0 операций).
    2. Сдвиньте ОДНУ балку в Archicad.
    3. 03-export.bat снова → появится ops.json (1 операция).
    4. Пришлите ops.json на машину B (мессенджер, облако, почта).
  На машине B (там, где применяют):
    1. Положите ops.json в папку кита.
    2. Сохраните копию PLN-файла!
    3. Откройте "тропу" в AC29, запустите 04-apply.bat,
       проверьте план, подтвердите буквой Y.
    4. Пришлите коллеге скриншот и файл ops_report.json.
  Повторное применение того же файла безопасно (дубли пропускаются).
  Если балку меняли на обеих машинах — будет CONFLICT, проект не тронется.

БЕЗОПАСНОСТЬ
  - Перед тестами синхронизации сохраните копию PLN-файла.
  - Отмена тестового сдвига: Ctrl+Z в Archicad.
  - Скрипты не удаляют файлы и не меняют настройки Windows,
    кроме тихой установки Python для текущего пользователя.
