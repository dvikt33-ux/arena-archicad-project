# Вторая машина: чек-лист к понедельнику 2026-09-14

Первый двухмашинный тест: A двигает балку → файл операций → B применяет.

## Что должно стоять на машине B

- [ ] Windows 10/11 x64.
- [ ] Archicad **29.0.0.3000 RUS** (та же сборка! проверить: Справка → О программе).
- [ ] Tapir **1.5.9** (`TapirAddOn_AC29_Win.apx`, SHA-256 `858ca5cf…1521566a`):
      скопировать в `C:\Program Files\GRAPHISOFT\ARCHICAD 29\Add-Ons\`,
      поставить «Разблокировать», перезапустить Archicad.
- [ ] Python 3.10+ (`py --version`).
- [ ] Во время теста запущен **только один** Archicad (26/27/28 закрыты), иначе порты
      разъедутся (см. урок: автоскан 19723–19727 обязателен).
- [ ] Кит `dist/accollab-kit-2026-09-11.zip` v4 (sha256 `764a157e…`): распаковать,
      прочитать INSTRUKTSIYA.txt в Блокноте, двойной клик `setup.bat` → сам ставит Python 3.12 (per-user, без админа),
      качает Tapir 1.5.9 с GitHub, снимает блокировку, запускает проверку.
      Связь между машинами только через интернет — файлы (кит, PLN, ops.json)
      носить мессенджером/облаком.

## Общий стартовый файл (КРИТИЧНО)

- [ ] Скопировать с машины A на машину B **тот же PLN-файл** «тропа архикад.pln»
      (флешка/Яндекс.Диск). НЕ пересоздавать, НЕ «Сохранить как» с изменениями:
      GUID элементов должны совпадать на обеих машинах.
- [ ] Перед тестом: Ctrl+Z до чистого состояния ИЛИ взять PLN до тестовых сдвигов
      (сейчас на A: БЛК-201 +1.0, БЛК-200 +0.5 от тестов №3).

## Проверка готовности (5 минут, на каждой машине)

1. Открыть «тропу» в AC29, палитра Tapir видна, About: 1.5.9.
2. `py collect_diag.py diag.json` (v2.1) → 393 элемента.
3. `py highlight_test.py` → 3 синие балки.

## Сценарий теста №4 (понедельник)

1. A: `py ops_export.py` (дам позже) — снимок базы.
2. A: сдвинуть одну балку вручную → `py ops_export.py` — файл `ops.json` (1 операция).
3. Перенести `ops.json` на B.
4. B: `py ops_apply.py ops.json` → подтвердить → балка двигается, сверка координат.
5. Оба: скриншоты результатов мне.

Инструменты `ops_export.py` / `ops_apply.py` выдам в понедельник утром вместе
с финальным прогоном тестов.
