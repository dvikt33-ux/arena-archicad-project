# Обновлённое ТЗ: обязательный результат — установщик для Archicad 29.0.0.3000+ (Windows x64)

Дата: 2026-09-11. Статус: ПЛАН (разработка не начата, сначала инвентаризация и решения).
Финальный артефакт: **один EXE-установщик**, ставящийся «из коробки» на чистый Windows 10/11 x64
с Archicad 29.0.0.3000+. Никаких «доустановите сами Python/Node/Git».

Честная оговорка о фазах (важно):
- **Фаза A (Tapir-only):** собственного APX ещё нет — установщик v0 ставит демон + проверяет/доставляет Tapir.
  Полноценный «APX нашего расширения» появляется только в **Фазе B (C++ Add-On)**.
- Финальный установщик (APX + демон + всё остальное) собирается после Фазы B.
  Ниже план сразу под финал, с пометками что в какой фазе.

## 3. Разделение компонентов

### 3.1. Необходимо для РАЗРАБОТКИ (у пользователя не ставится)
D2 (образцы), D4 (DevKit), D5 (VS2022), D6 (Python+PyInstaller), D7 (Inno), D11 (VM),
исходники C++/Python, тесты, `collect_diag.py`.

### 3.2. Необходимо для РАБОТЫ пользователя (едет внутри установщика, отдельно не ставится)
- Наш `ACCollab.apx` (Фаза B) → в `Add-Ons` выбранной установки Archicad.
- `accollab-daemon.exe` (PyInstaller one-dir, свой Python внутри) → `%LOCALAPPDATA%\AC-Collab\` (per-user) или `%PROGRAMFILES%\AC-Collab\` (per-machine).
- SQLite-база (WAL) — создаётся при первом запуске, файл `collab.db`, мигратор внутри демона. Никакого «установите БД».
- Конфиг `config.json` (создаёт установщик + первый запуск), папки `logs/`, `backups/`, `outbox/`.
- Локальная веб-панель — раздаётся самим демоном на `127.0.0.1` (браузер уже есть в Windows, Electron НЕ везём).
- Tapir APX — только если не найден подходящий: ставится из комплекта (MIT, с LICENSE) в тот же `Add-Ons`.
- Ярлыки: «AC-Collab Панель», «AC-Collab Диагностика», деинсталлятор. Опционально автозапуск демона.

### 3.3. Необходимо ТОЛЬКО ДЛЯ СБОРКИ установщика (не едет пользователю)
D4, D5, D6, D7, D8 (сертификат), Inno-скрипт `installer/setup.iss`, `build.bat`, CI-манифест,
контрольные суммы, тестовые скрипты установки.

## 6. Технология установщика (предложение)

**Основной: Inno Setup 6 (EXE).** Причины:
- Один EXE, работает на чистой Windows без предустановок, русский язык мастера из коробки.
- Pascal-скрипт: произвольные проверки (реестр, версия `Archicad.exe`, папка Add-Ons, порт, хэши).
- Режимы `/SILENT`, `/VERYSILENT`, `/DIR=`, `/TASKS=` — тихая установка для 6 машин.
- Поддержка подписи, журнала установки, отката, условной эскалации прав (admin только для записи в Program Files).
- Бесплатен, зрелый, установщики third-party Add-On для Archicad обычно делают именно так [2](https://bimdots.com/manuals/add-on-installation-guide/).

**Дополнительно:**
- Portable-ZIP (тот же комплект без мастера) — для диагностики и ручной установки.
- MSI через WiX — только если позже понадобится раскатка через GPO/Intune; в v1 не делать (двойная поддержка).

**Подпись:** без Authenticode-сертификата Windows покажет SmartScreen-предупреждение.
Тестовые сборки — без подписи (честно пишем в отчёте); релиз — с подписью после получения сертификата.
Обновления проверяют подпись нового пакета перед применением.

## 7. План сборки на чистом Windows 10/11 x64 (сборочная машина)

Требования к машине сборки (НЕ машина пользователя, можно VM/CI):
1. Windows 10 22H2 / 11 x64, ~30 ГБ свободно, интернет на время сборки.
2. `git`, Python **3.11.x x64** (точная версия фиксируется в `build/pins.txt`), `pip install -r build/requirements.txt` (pip freeze в отчёт).
3. Visual Studio с тулсейтом **v143** (проверенный рецепт для APX под AC29 — из CI Tapir: CMake `-G "Visual Studio 17 2022" -A x64 -T v143`; у заказчика VS2026 Community 18.10.12201.205 — доустановить компонент «MSVC v143» через VS Installer) + Windows SDK + **CMake 3.2x** — только для Фазы B (APX).
4. DevKit 29.3000 — **не коммитить и не прикладывать**: `build.bat`/CI скачивает `API.Development.Kit.WIN.29.3000.zip` с официального релиза Graphisoft во временную папку сборки (лицензия SLA запрещает распространение).
5. Inno Setup 6.x (путь `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`).
6. (Опционально) `signtool` + сертификат — шаг подписи.

**Одна команда:**
```bat
git clone <repo> accollab && cd accollab
build.bat --config Release --arch x64
```
Шаги `build.bat`: проверка инструментов → `doctor` окружения → сборка демона (PyInstaller)
→ сборка APX (MSVC, Фаза B) → проверка лицензий → ISCC → подпись (если есть cert) →
`dist\AC-Collab-Setup-<ver>.exe` + `SHA256SUMS.txt` + `install-report.txt`.

**Альтернатива без своей машины:** GitHub Actions `windows-latest` по тому же `build.bat`
(DevKit кладётся в CI как защищённый артефакт из официального источника, ключ — в Secrets;
детали согласуем, когда дойдём).

## 8. Проверка совместимости с Archicad 29.0.0.3000 (логика установщика)

Порядок проверок в мастере (каждая с понятным сообщением и кнопкой «Подробнее»):
1. **Windows:** `IsWin64` + версия ≥ Win10 1809. Иначе — отказ с объяснением.
2. **Поиск Archicad:** реестр (`HKLM/HKCU …\GRAPHISOFT…`), стандартные пути
   (`C:\Program Files\Graphisoft\Archicad 29*`), далее — версия файла `Archicad.exe`
   (FileVersion: major == 29, build >= 3000; эталон — ровно 29.0.0.3000, билды выше — с предупреждением до отдельного теста). Найденные установки — списком на выбор.
3. **Отказ чужим версиям:** major 28/30/31 — не ставим APX, показываем почему;
   ссылку «поддерживаемые версии» ведём на `SUPPORTED-VERSIONS.txt` (пока только 29.x).
4. **Нестандартный путь:** если авто-поиск пуст — диалог ручного выбора папки с валидацией
   (есть `Archicad.exe` + версия + папка `Add-Ons*` с учётом локализованных имён). В случайное место не копируем.
5. **Папка Add-Ons:** определяем фактическую (`Add-Ons`, локализованные варианты, designated dir);
   наш APX — только туда; при отсутствии прав — точечная эскалация admin с объяснением.
6. **Tapir:** ищем Tapir-APX и его версию в Add-Ons; если нет/старый — предлагаем поставить из комплекта (MIT).
   При копировании APX/EXE снимать блокировку Zone.Identifier (Mark-of-the-Web), иначе Windows/Archicad могут молча не загрузить файл.
7. **Конфликты:** ищем наш старый APX/другой версии → предложение «Обновить» (бэкап старого → замена → откат при ошибке).
8. **Демон:** свободный порт панели, запись в `%LOCALAPPDATA%` (per-user, без admin) или Program Files (per-machine, с admin).
9. **Верификация после копирования:** SHA-256 каждого файла из манифеста, `daemon --health`,
   пробный запуск панели, итоговая страница «что и куда установлено» + путь к логу.
10. **Удаление:** только файлы из нашего манифеста + ярлыки + автозапуск; SQLite/бэкапы — по выбору
    («сохранить журнал и бэкапы» по умолчанию ВКЛ); PLN/проекты/Archicad не трогаем никогда.

Первый запуск Archicad после установки: Add-On Manager должен показать наш APX как загруженный
(Фаза B) / демон — зелёный статус подключения к Tapir (Фаза A). `doctor` перепроверяет это одной кнопкой.
