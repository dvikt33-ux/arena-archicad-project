## 🔴 MUST-HAVE (без этого прототип будет «сферическим»)

### 1. Окружение каждой машины (таблица, 3–6 строк)
Для каждой рабочей машины:
- Версия Windows (Win10/11, сборка, x64)
- Archicad 29 точный билд (Справка → О программе → номер сборки, напр. 29.0.0.xxxx)
- Установлен ли Tapir Add-On? Какая версия? (если нет — поставим, напишите «нет»)
- Python: установлен? версия? (`python --version`) Есть ли права админа для установки Python 3.11+ и pip-пакетов?
- Сеть: все в одном офисе/LAN или часть удалённо? Видят ли друг друга (ping)? Можно ли открыть один TCP-порт (напр. 8765)? Разрешён ли mDNS/Bonjour? Можно ли поставить Tailscale/WireGuard (для интернета без центрального сервера)?
- Кто администрирует сеть (можете ли вы сами разрешить порт/фаервол)?

Формат: обычная таблица в Excel/Markdown/тексте. Пример строки:
`WS-01 | Win11 23H2 | AC29 build 4001 | Tapir 1.9.x | Python 3.11.9, admin есть | LAN 192.168.1.x, ping ok, порт открыть можно`

### 2. Проект-образец (один файл)
Один репрезентативный, но НЕ гигантский проект:
- Формат: `.PLN` (если библиотеки внешние — лучше `.PLA`, чтобы открылся везде).
- Размер: идеально 5–50 МБ. Полный 2 ГБ генплан не нужен.
- Состав: стены + перекрытия + хотя бы 1–2 зоны + хотя бы 1 Morph + 1–2 листа/чертежа (если используете). Если есть Hotlink-модули — скажите отдельно, файл hotlink'а тоже нужен или инструкция «без него».
- Конфиденциальность: сделайте Sanitized-копию: «Сохранить как…», удалите персональные данные заказчика, оставьте структуру/типы. Мне не нужны реальные адреса/ФИО/цены.
- Плюс цифры: сколько этажей, примерное число элементов (можно грубо), сколько видов/макетов.

Как приложить: прикрепите файл к сообщению (если большой — залейте на Яндекс.Диск и дайте ссылку + скажите, что там).

### 3. Кто эти 3–6 человек и как делят работу
- Список: имя/ник, роль (архитектура / конструкции / генплан / документация…), что обычно трогает.
- Типичный конфликт из жизни: «двое полезли в одну стену», «кто-то удалил зону, а у другого площадь поплыла» — 2–3 реальных примера.
- Что болит сильнее всего прямо сейчас? Проранжируйте 1→5: блокировки / история-откат / офлайн-синхронизация / комментарии / контроль стандартов.
- Бывает ли офлайн (обрывы, удалёнка, командировки)? Как часто и насколько долго?

### 4. Два решения (ответьте одной строкой на каждое)
- **Путь:** A) Tapir-only прототип быстро (рекомендую) или B) сразу с C++ Add-On долго. Если молчите — иду по A.
- **Сеть v1:** A) только LAN + ручной перенос файла или B) LAN + инструкция Tailscale/WireGuard. Если молчите — делаю A, инструкцию для B прикладываю отдельно.

### 6. Диагностика из живого Archicad (5 минут на одной машине)
Поставьте Tapir (если ещё нет), откройте проект-образец, выполните приложенный скрипт
`tools/collect_diag.py` (ничего не меняет, только читает) и пришлите получившийся
`diag_output.json`. Там: ProjectInfo, число элементов по типам, пара примеров GUID/details,
версия Tapir. Это позволит мне привязать схемы к вашей реальности, а не к документации.

```powershell
# на машине с Archicad 29 + Tapir, проект открыт:
py -3.11 -m pip install archicad
py tools/collect_diag.py > diag_output.json
```

(Если `archicad`-пакет не ставится — напишите текст ошибки, дам вариант через чистый `urllib`.)
