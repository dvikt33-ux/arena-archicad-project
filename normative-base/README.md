# Нормативная база для проектирующего агента

Статус: рабочая проверенная база v1. Проверено: 2026-09-30.

Цель — давать агенту не просто список СП/ГОСТ, а правила применения при построении BIM-модели: координационные размеры, допустимые типоразмеры, ограничения, источники и запреты на автоматическое принятие проектных решений там, где необходим расчет или выбор по назначению здания.

## Принципы

1. Не считать номер СП/ГОСТ сам по себе доказательством актуальности. Проверять статус и изменения на портале Росстандарта.
2. Юридическую применимость требования проверять отдельно по Реестру требований ЕИС «Стройкомплекс.РФ». ПП РФ №815 утратило силу с 2024-09-01.
3. Хранить `effective_from`, `replaces`, `amendments`, `checked_at`, `source_url`.
4. Автоматически применять только правила со статусом `auto_rule: true`.
5. Размер изделия не равен автоматически проектному координационному размеру. Различать номинальный/координационный, конструктивный и фактический размеры.
6. Не выводить несущую способность, глубину опирания, марку материала, армирование, предел огнестойкости, ширину эвакуации или толщину ограждения только из «типового» значения — если норма требует расчета или выбора по условиям, агент должен запросить/выполнить расчет.
7. При коллизии между общей и специальной нормой применять специальную норму для конкретного функционального назначения и фиксировать источник решения.

## Структура

- `registry.yaml` — проверенные действующие документы и замены.
- `rules/00_modular_coordination.yaml` — модульная координация.
- `rules/01_masonry.yaml` — кирпич, кладочные швы, простенки.
- `rules/02_precast_floor_slabs.yaml` — сборные железобетонные плиты перекрытия.
- `rules/03_egress_and_accessibility.yaml` — эвакуация, лестницы, МГН.
- `rules/04_architectural_baseline.yaml` — базовые документы архитектора.
- `AUDIT.md` — найденные замены, стоп-лист и правила повторной проверки.

## Важно для генерации модели

Базовая сетка здания не должна бездумно округляться «до 100 мм». ГОСТ 28984-2011 задает основной модуль М=100 мм и набор укрупненных/дробных модулей, но выбор сетки должен соответствовать конструктивной системе и изделиям. Для кирпичной кладки геометрический шаг ряда определяется фактическим размером изделия и нормативным швом; для сборных плит используются координационные размеры из стандарта конкретного изделия.

Эта база намеренно консервативна: отсутствие правила означает «не автоматизировать», а не «можно как угодно».
